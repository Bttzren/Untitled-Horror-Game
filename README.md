# Untitled Horror Game

A co-op horror game for 1–4 players that runs in a web browser. You and your
friends go into a stranger's nightmare, carry their memories back to the Door,
and try not to be found. No weapons: you run, hide, and learn the rules of
whatever is in there with you.

Status: first playable version. Expect things to change.

## How a night works

1. One player hosts a room and shares the 5-character code. Friends join with it.
2. The host starts the night. Everyone appears at the Door inside a dream that is
   laid out differently every night.
3. Find memories, carry them back to the Door, and press E to bank them.
4. When the banked value reaches the quota, the Door opens. Press E twice at the
   Door with empty hands to leave (twice, because leaving cannot be undone).
5. The night lasts 8 minutes. Halfway through, lights start failing and a second
   entity wakes. At zero the dream collapses on anyone still inside.

You win the night if the quota is met and at least one player left through the
Door. Then the next night has a bigger quota and a bigger dream. If the quota is
missed, or everyone is caught, the run starts again from night 1.

### What is in there

- **The Usher** only moves while nobody is looking at it. Keep it in view and it
  is a statue. Look away and it is faster than you. It clicks when it moves.
- **The Listener** is blind and follows sound. Sprinting is loud, walking is
  quieter, crouching is silent. Some memories ring or play music. It catches
  anyone it bumps into, so do not let it walk into you.

Lockers and curtains hide you. The Usher still finds you if it watched you get in.

## Controls

| Action | Key |
|---|---|
| Move | W A S D |
| Look | Mouse (click the game first) |
| Sprint | Shift |
| Crouch | C (or left Ctrl) |
| Interact: take, bank, hide, leave | E |
| Drop what you carry | Q |
| Throw what you carry | Left click |
| Flashlight | F |
| Pause menu: controls, mouse speed, volume, leave | Esc |

Use C to crouch rather than Ctrl: in most browsers Ctrl+W closes the tab.

Heavier memories are worth more but slow you down, and the heaviest stop you
sprinting. Throwing a memory makes a loud noise where it lands, which is a good
way to send the Listener somewhere else.

## Run it on your computer

You need [Node.js](https://nodejs.org) 22 or newer.

```bash
npm install
```

```bash
npm run dev
```

Then open the address it prints (usually http://localhost:5173).

## Play with friends

Everyone needs to open the same copy of the game on the web, so put it online
first. The simplest way is itch.io:

```bash
npm run package
```

That creates `release/untitled-horror-game.zip`. On itch.io, create a new
project, set **Kind of project** to **HTML**, upload the zip, and tick **This
file will be played in the browser**. A size of 1280 × 720 with the fullscreen
button enabled works well. You can keep the page as a draft or restricted and
still share its link with friends.

Then one of you clicks **Host a room** and reads out the code, and the others
type it in and click **Join**.

Things to know:

- The host's browser runs the night. If the host closes the tab, the night ends
  for everyone.
- Players connect directly to each other. Some school and work networks block
  that; if joining fails with a network message, try a home network or a phone
  hotspot.
- Finding each other uses the free public PeerJS server. If it is down, hosting
  and joining show "Couldn't reach the matchmaking server"; try again later.
- It is built for desktop browsers with a keyboard and mouse.
- There is no voice chat yet. Use a call alongside the game.

## Working on the game

```bash
npm test
```

runs the rule tests (movement, memories, entities, networking).

```bash
npm run e2e -- --trace off
```

runs the browser tests, which host and join real rooms on your machine.

Where things live:

| Folder | What it holds |
|---|---|
| `src/rules` | The game's rules, with no graphics. `config.ts` has every number worth tuning: speeds, night length, quota, noise distances. |
| `src/rules/entities` | One file per entity. To add one, copy a file, give it a rule, and register it in `index.ts`. |
| `src/dream` | Builds each night's map from a seed number. |
| `src/net` | Hosting, joining and keeping everyone in sync. |
| `src/view` | Drawing, sound, menus and the in-game overlay. |
| `public/assets` | Models made by other people. |
| `docs/superpowers` | The design document and the build plan. |

## Credits

The rooms, entities and all sound are generated by the game's own code. A few
models come from other people who shared them freely; they are listed with
their licences on the **Credits** screen in the main menu, and in
`src/view/credits.ts`. Any file added to `public/assets` must be added to that
list (a test checks this), and only CC0 or CC-BY assets are used.
